ফয়সাল অর্গানিক ফুড — ওয়েবসাইট ফাইল

শুরু করার নিয়ম:
1. ZIP ফাইল Extract করুন।
2. index.html ফাইলটি Chrome-এ খুললে ওয়েবসাইট দেখা যাবে।
3. অনলাইনে প্রকাশ করতে index.html, style.css, script.js একই ফোল্ডারে রাখুন এবং GitHub Pages/Netlify-তে আপলোড করুন।

- script.js ফাইল খুলুন।
- শুরুতে products তালিকার name, icon, desc, price পরিবর্তন করুন।
- দাম আপাতত "০০০" রাখা হয়েছে।
- icon-এ ইমোজির বদলে নিজের পণ্যের ছবির ব্যবস্থা চাইলে পরের সংস্করণে image field যোগ করা যাবে।
